=== How our Project is Structured ===
The project is pretty straight forward when it comes to its structure. The root folder contains the assets, scenes, and scripts folders.

The assets folder contains everything related to the visuals of the game, whether it's tile sets, fonts, music, or sounds.

The scenes folder is where the files for each of the individual pieces of the game are stored. Multiple scenes are then put together into one scene to create a level. 

The scripts folder contains the files that are required for connecting the backend part of the scenes to each other, in order to make sure everything functions as intended.

=== Downloading the Latest Version of the Game ===
On the GitHub Repository code page, on the right hand side of the page, there is a section titled "Releases" where you can click on the latest version of "Guns Up!". There will be four files in the release. If you are using a computer running MacOS, download the "Guns.Up.MacOS.zip" file. For Windows, download the "Guns.Up.Windows.zip" file. For Windows, extract the zip file and then open the "Windows" folder and then double-click on the .exe file. For MacOS, double click the Guns.Up.MacOS.zip file to extract it and then double click the application to launch it.
